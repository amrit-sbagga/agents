1 - Create the project using
> crewai create crew <project-name>


2 - Configure yaml config files - for agents & tasks

3 - Create & update files -> 
  a - crew.py(for agents, tasks & crew referencing the config) & 
  b - main.py(for setting inputs)


4 - Enable tracing
> crewai traces enable
(crewai login first here - required one time)

5 - Run the project
> crewai run
